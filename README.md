# 美食发生器

八大菜系各 30 道经典菜，随机撞一道出来。不知道吃什么、或者想练手做菜的时候跑一下。

## 用法

```bash
python3 美食发生器.py          # 随机菜系随机菜
python3 美食发生器.py 川菜      # 只从川菜里抽
python3 美食发生器.py 列表      # 各菜系有多少道
```

按回车出下一道，输入 `q` 退出。

## 菜系

鲁菜、川菜、粤菜、苏菜、浙菜、闽菜、湘菜、徽菜，每个 30 道，共 240 道。

## 说明

已避开动物内脏类食材（肠、肚、腰、肝、肺、血、心、百叶、黄喉、脑、胗、杂、蹄筋、肾、胰），
脚本里有一层关键词过滤做双保险，抽到就跳过。
